# tools — рабочие скрипты

Запускать **из папки `api`**, иначе не найдутся модули проекта:

```
cd api
python ..\tools\rt_watch.py
```

## Смотреть

| Скрипт | Что делает |
|---|---|
| `rt_watch.py` | сторож кампании: темп, сбои, флуды, узкие места |
| `анализ.py` | разбор за несколько дней: комменты, ошибки, аккаунты, каналы |
| `день.py` | короткая сводка по дням |
| `funnel_full.py` | сколько заявок в воронку — и ждущих, и принятых |
| `funnel_today.py` | заявки за сегодня (только ждущие решения) |
| `which_channel.py` | какой канал прикреплён к аккаунту |

## Аккаунты

| Скрипт | Что делает |
|---|---|
| `ask_ids.py` | опрос @SpamBot по списку номеров |
| `limits_full.py` | то же, но с полным текстом ответа и кнопками |
| `limits_until.py` | вытащить дату снятия ограничения и записать в реестр |
| `login_code.py` | достать код входа, присланный в приложение |
| `export_session.py` | выгрузить сессию строкой для другой программы |
| `dress_up.py`, `fix_and_list.py` | оформление профилей: аватар, имя, ник, канал |
| `link7.py` | выдать персональные ссылки на воронку и прикрепить каналы |

## Подписки и каналы

| Скрипт | Что делает |
|---|---|
| `subs50k.py` | подписать на каналы от 50к, где можно писать |
| `second_member.py` | посадить второго участника в каналы с подтверждённым опытом |
| `mode_setup.py` | разметить каналы: комментируем / только реакции / мёртвый |
| `tgstat_harvest.py` | собирать каналы с TGStat из живого браузера |

## Реакции

| Скрипт | Что делает |
|---|---|
| `react_fresh.py` | пройдёт ли реакция свежим аккаунтом, который там не писал |
| `chat_react.py` | проходят ли реакции на комментарии (главное — трафик оттуда) |
| `react_retry.py` | не забанили ли за сами реакции |

## Антидетект

| Скрипт | Что делает |
|---|---|
| `map_profiles.py` | какие аккаунты в каких профилях браузера |
| `peek_profile.py` | заглянуть в хранилище профиля |

---

Почти все умеют `--help`. Те, что меняют данные, обычно требуют `--apply`
— без него показывают, что собираются сделать, и выходят.
